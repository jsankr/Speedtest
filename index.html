Prefix base

1 byte = 8 bits, so 1 MB/s = 8 Mbps and 1 GB/s = 8 Gbps. Internet plans are sold in bits (Mbps/Gbps); file downloads show bytes (MB/s). Each test moves roughly your speed × twice the phase length, so lower the seconds per phase on mobile data.
